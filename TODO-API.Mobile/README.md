# TODO API Mobile

Это отдельное мобильное приложение (.NET MAUI) для работы с существующим TODO API.

## Как использовать

1. Запустите сервер TODO API.
2. Откройте `TODO-API.Mobile.sln` в Visual Studio (Windows или macOS) с установленной нагрузкой .NET MAUI.
3. Запустите приложение на эмуляторе или устройстве.
4. Введите базовый URL API в приложение. Для Android-эмулятора используйте `http://10.0.2.2:5000`.

Приложение хранит базовый URL в настройках и позволяет:
- просматривать задачи;
- добавлять новые;
- отмечать выполненными;
- удалять.
